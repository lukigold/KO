# Licensing

KO is open source. The product is share-alike, so improvements stay open. The module interface is
permissive, so anyone can build modules for KO, including closed commercial ones.

| Hardware: PCBs, case and mechanical designs | CERN-OHL-S-2.0 | [LICENSES/CERN-OHL-S-2.0.txt](LICENSES/CERN-OHL-S-2.0.txt) |
| Documentation (except the module spec) | CC-BY-SA-4.0 | [LICENSES/CC-BY-SA-4.0.txt](LICENSES/CC-BY-SA-4.0.txt) |
| Module interface spec ([docs/contracts/module-interface.md](docs/contracts/module-interface.md)) | CC-BY-4.0 | [LICENSES/CC-BY-4.0.txt](LICENSES/CC-BY-4.0.txt) |
| Module reference code (`ko-module-bus` and the module-facing parts of `ko-protocol`) | MIT OR Apache-2.0 | [LICENSES/MIT.txt](LICENSES/MIT.txt), [LICENSES/Apache-2.0.txt](LICENSES/Apache-2.0.txt) |
