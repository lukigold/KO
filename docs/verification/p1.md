| Track widths on power nets | script over the routed board | every charging, boost, battery, LED and VBUS current path on 0.6–1.0 mm hand-drawn copper; below class width only low-current branches (module VBUS pad, TPS2116 MODE, 74AHCT1G125 supply, module VCC ≤ 25 mA, haptic logic supply) |
| Manufacturing files | `fab_outputs.py` | Gerbers, drills, BOM 42 lines, CPL 81 parts (J501 the only bottom part), 1:1 PDF, renders |

Router fixes found on the way (`route_pcb.py`): the repair mode wrote every stored route back at the width of its
first segment, which turned a 0.15 mm fallback branch into 0.3 mm and broke clearances; it also dropped vias that no
stored track touches. Both fixed. The polish mode now removes a whole dead branch, not one segment per pass.

Known compromise, written down in the design note: C203 (4.7 µF on VBUS) is about 20 mm from module pad 66.

  switch board.
- Part rotations in JLCPCB's placement preview; TS3USB221A stock in the BOM step.
- Everything in the rev A verification plan (bench tests once boards arrive).
